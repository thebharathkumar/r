# Cheer Up Rambab 💝

A heartfelt, animated website to clear up misunderstandings and bring a smile!

## Features

- Beautiful animated gradient background
- Floating hearts and sparkles
- Interactive elements with emoji rain
- Personalized apology message
- References to favorite things: Korean food, matcha, gym, haircuts, and more!

## Deploy to Vercel

### Option 1: Deploy via Vercel CLI

1. Install Vercel CLI (if not already installed):
   ```bash
   npm i -g vercel
   ```

2. Login to Vercel:
   ```bash
   vercel login
   ```

3. Deploy:
   ```bash
   vercel
   ```

4. For production deployment:
   ```bash
   vercel --prod
   ```

### Option 2: Deploy via Vercel Dashboard

1. Go to [vercel.com](https://vercel.com)
2. Sign in with your account
3. Click "Add New Project"
4. Import your Git repository
5. Vercel will automatically detect it's a static site
6. Click "Deploy"

### Option 3: Deploy from GitHub

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "Add New Project"
4. Select your repository
5. Click "Deploy"

## Local Development
